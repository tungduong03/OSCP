##

Mục tiêu:

- Gửi cho nạn nhân file `config.Library-ms`
- Khi nạn nhân mở file:
    Windows Explorer hiển thị nội dung từ WebDAV server của attacker như thư mục local
- Trong “thư mục” đó có file `.lnk`
- User click `.lnk`
- `.lnk` chạy PowerShell → tải payload → reverse shell

### Windows Library File là gì?

File `.Library-ms` là:

- file XML của Windows
- dùng để tạo “virtual folder”
- có thể trỏ tới:
    - local path
    - SMB share
    - WebDAV
    - cloud location

- Khi double-click:

    Windows Explorer mở nó như folder thật
    user thường không nhận ra đây là remote resource

=> Đây là điểm abuse.


### Tool dùng: WsgiDAV

Cài:

`pip3 install wsgidav`

Chạy:

`wsgidav --host=0.0.0.0 --port=80 --auth=anonymous --root /home/kali/webdav/`

Option:
- `--host=0.0.0.0`	listen mọi interface
- `--port=80`	chạy HTTP
- `--auth=anonymous`	không cần auth
- `--root`	folder share
